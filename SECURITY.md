# Security

Brave New World is a static front-end. It has no backend, accounts, or API keys.

Please **do not** open issues or pull requests that include:

- Secrets, tokens, passwords, or `.env` values
- Server hostnames, bind addresses, logs, or PID files from a private deployment
- Studio trailers or other footage you do not have the right to redistribute

Report a vulnerability privately to the repository owner rather than filing a public issue.
